## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ejneuro/eugineweks.git
   cd eugineweks
   ```

2. Serve locally (requires a simple HTTP server):
   ```bash
   python -m http.server 8000
   # or
   npx http-server
   ```

3. Open `http://localhost:8000` in your browser.
